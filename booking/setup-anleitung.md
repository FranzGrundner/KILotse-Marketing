## 1. Calendly (oder TidyCal) einrichten

### Calendly (kostenlos)

1. Konto unter https://calendly.com anlegen (Google-Login reicht).
2. **URL-Slug:** z. B. `franz-ki-lotse`
3. **Event-Typ anlegen:**
   - Name: `Gratis KI-Check (30 Min)` / `Free AI Workflow Check (30 Min)`
   - Dauer: **30 Minuten**
   - Ort: `Google Meet`, `LINE Video Call` oder „In-person — Pattaya“
   - Verfügbarkeit: nur Zeiten, die du wirklich hast (z. B. Di/Do 10–12, 15–17), Zeitzone **Asia/Bangkok**
4. **Fragen beim Buchen** (optional, hilfreich):
   - „Was ist deine größte zeitfressende Aufgabe gerade?“ (Freitext)
   - „Bevorzugte Sprache: DE / EN“
   - „LINE-ID (falls schon vorhanden)“ (Freitext)
5. **Bestätigungsmail** anpassen:
   > Danke für die Buchung! Ich melde mich kurz vor dem Termin per LINE. Falls du mich noch nicht auf LINE hast: [LINE-Link]. Bei Fragen vorab einfach schreiben.

6. Link kopieren → z. B. `https://calendly.com/franz-ki-lotse/30min/ki-check`

**Link hier eintragen:**

```
Calendly/TidyCal: ___________________________________
```

## 2. LINE vorbereiten (Hauptkanal)

1. LINE App → **Einstellungen** → **Profil** → **LINE-ID** festlegen (z. B. `franz.kilotse`)
2. **Mein QR-Code** → Link kopieren oder Screenshot für Linktree speichern
3. Freund-Link Format: `https://line.me/ti/p/~franz.kilotse` (deine ID einsetzen)
4. Optional **LINE Official Account** später — für Phase 1 reicht persönliche LINE-ID
5. Away-Message / Status (optional):
   > Franz · KI-Lotse · Pattaya — Antwort meist innerhalb 24h. Gratis Gespräch: https://calendly.com/franz-ki-lotse/30min

**LINE-ID / Link eintragen:**

```
LINE-ID:   franz.kilotse
LINE-Link: https://line.me/ti/p/~franz.kilotse
```

